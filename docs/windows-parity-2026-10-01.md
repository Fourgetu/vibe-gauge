## 网络体检

- 网络页新增独立体检卡片，保留折叠的完整诊断。
- DNS：国内公共 DNS 显示“需关注”；全部 DNS 指向 Fake-IP 网段时显示代理接管特征；路由器、本地回环或混合配置显示“无法判定”。这些是本机配置线索，不宣称已经证实泄漏或绝对安全。
- IPv6：强制 IPv6 socket、禁用系统 HTTP 代理；同时执行强制 IPv4 的对照请求。IPv6 收到任意 HTTP 响应，即使没有有效 trace 或返回 403，也表示存在可达路径。
- 仅在 IPv4 对照可达、IPv6 因解析/连接/超时失败时，显示“本次未发现 IPv6 直连”。离线、TLS 等其他错误显示未知。
- 禁用系统 HTTP 代理不能绕过操作系统路由，TUN 或软路由仍可能转发请求；警告只表示可能绕过代理策略。

## 刷新路径

| 内容 | 周期 / 条件 |
| --- | --- |
| 客户端进程状态 | 订阅页可见时约 1 秒，Toolhelp 快照 + 已验证进程元数据 |
| 网络速率 | 网络页可见时约 1 秒，只更新已有速率文本 |

| Codex 官方额度 | 保持 60 秒 |

窗口隐藏或进入其他页面时停止每秒任务。轻量任务不调用 WMI、日志扫描、额度请求、清理策略或托盘通知；不会每秒重建项目/统计/网络整页。重叠 tick 不排队，隐藏、切页、完整快照更新、退出会丢弃过期结果。进程元数据复用前验证 PID、启动时间和名称，避免 PID 重用导致误判。

只靠命令行才能识别的新 `node` CLI 仍由 5 秒扫描发现；已识别进程的退出和可直接识别的原生客户端由轻量快照更新。会话内容和 token 消耗不是每秒扫描。
