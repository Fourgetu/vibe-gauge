# Windows 设置页重排验收（2026-09-30）

## 更新检查的含义

上游 `Sources/UpdateChecker.swift` 检查 `MaxHaiCom/VibeGauge` 的 GitHub 最新软件 release，最多每天一次，只提示，不自动安装。它不是操作系统更新检查。

Windows 的 `windows/src/VibeGauge.Windows/Services/UpdateChecker.cs` 检查 `Fourgetu/vibe-gauge` 的软件 release，并筛选适用的 Windows 包。此前“Windows 版本更新”及英文“Windows updates”容易被理解成系统更新。本轮改为“检查软件更新”及“VibeGauge 软件更新”，版本详情明确区分软件发行包和 Windows 系统更新。

## 界面处理

- 以用户提供的上游截图为设置页参考：圆角卡片、标题及说明纵向排列、右侧统一开关；取消连续七个折叠标题和直接暴露的代理表单。
- 主卡片提供自动清理、登录启动、阈值通知、出口变化通知、软件更新、Claude Code/AGY 额度连接、待处理会话和额度预测通知。开关读取现有状态，加载页面不保存或启用设置。
- 阈值通知总开关控制额度、内存和磁盘通知；二级页面仍可单独设置，任一子项开启时总开关显示开启。
- 通知与阈值、网络诊断、成本与套餐、磁盘维护、软件版本、官方 CLI、代理连接移入可返回的二级页面。保留原有操作和确认流程，Escape 可返回设置。
- 登录启动移入设置卡，底栏保留退出、状态和语言分段按钮。保留跟随系统、中文、英文三种语言选择。
- 缩短英文导航标签为 Plans / Stats，避免 420 像素窄窗中右上角按钮被挤出。
- 复用亮暗主题颜色，说明自动换行，开关与详情入口箭头右对齐。没有改变开关默认值来模仿上游截图中的开启状态。

## 交付和边界

预览包：`windows/artifacts/settings-redesign-20260930/VibeGauge-1.6.5-settings-preview-win-x64.zip`。

解压后通过 `Start-Preview.ps1` 启动隔离数据预览，进入系统页后向下滚动到设置。脚本使用包内 `preview-data`，默认关闭自动清理、自动网络诊断和自动更新检查。直接运行主程序仍使用正常用户数据目录。隔离数据不隔离系统操作：开机启动等设置仍作用于本机。

包内 `screenshots` 为隔离测试渲染，不代表真实账号、用量或网络探测结果。本轮没有执行真实账号查询、CLI 安装登录、清理操作或操作系统更新，没有安装替换现有版本，也没有提交、推送或发布 GitHub release。设置页设计已按参考重做，但不据此声称整个 Windows 应用与 macOS 上游逐像素一致或完成全部真实环境功能验证。
