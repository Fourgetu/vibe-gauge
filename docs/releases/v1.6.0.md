# VibeGauge v1.6.0

Windows 新增 ZCode 用量监控与更紧凑的订阅面板。保留历史用量、系统页版本号、浅深色毛玻璃、贴顶收缩及已有监控能力。macOS 功能实现不变，随版本提供 Universal 构建。

## 新增与改进

- **ZCode 监控**：只读获取本地 ZCode 数据库的逐次模型调用，显示运行状态、今日总 Token、调用次数和本地累计用量；接入总览、近期调用、所选日期/模型分布、日历和小时统计。
- **Gemini / ZCode 左右排列**：原 Gemini 整行改为左侧 Gemini、右侧 ZCode；Gemini 的原生及 3P 额度信息仍保留。
- **压缩两排卡片高度**：PI-Desktop / Ollama 行与自定义 sub2api 卡片采用紧凑摘要，避免完整用量明细撑高面板，保留原有正文字号。
- **悬停查看完整信息**：鼠标停留在卡片区域可查看完整明细、精确总 Token、重置时间、额度可信度及预测；浅深色高对比提示框自动换行。
- **ZCode 删除会话不回退**：按请求 ID 保留已读取的统计，删除会话、源记录或数据库并重启后仍保留；恢复相同记录不重复累计。

## 统计与安全边界

- ZCode 总 Token = 已归一化的输入 + 输出；缓存已包含在输入内，思考已包含在输出内，不重复相加。
- 仅记录已结束且报告用量的请求；运行中请求等待结束。读取失败会显示提示并保留旧值。
- 只读取用量元数据，不读取对话正文或密钥，不修改 ZCode 程序、快捷方式、设置或数据库内容。
- 本地累计不等于完整账号账单：首次监控前已删除的数据无法恢复，其他设备用量不在其中。独立 API 代理统计不混入桌面统计。
- 数据库与 WAL 未变化时跳过重复读取；未新增后台服务或常驻数据库连接。
