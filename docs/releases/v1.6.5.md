# VibeGauge v1.6.5

Windows 统计页、设置、网络诊断与计价更新，包含本轮上游行为审计修复。macOS 实现保持不变，随版本提供 Universal 构建。

## 统计与计价

- **四张汇总卡片**：总 Token、API 等价成本、活跃天数、缓存命中率以 2×2 排列，跟随时间范围或所选日期。
- **Token 分布**：新输入、输出、缓存以堆叠条和图例展示；缓存包括读取与写入，思考作为输出明细，不重复计入总量。
- **模型构成**：以输入（含缓存）加输出计算占比，同名模型跨来源合并。默认只展示前两个，点击可展开全部或收起；堆叠条和百分比分母始终包含全部模型。
- **独立 Agent 用量**：按工具展示总 Token、占比、调用、输入输出、缓存、思考和估算成本；同名模型在各工具中的消耗分别汇总。
- **OpenRouter 公开价格**：在“系统 → 详细设置 → API 成本与套餐”点击“使用 / 更新 OpenRouter 价格”。无需密钥，不上传用量；替换价格表前自动备份，网络或目录解析失败保留旧表。
- **模型别名**：OpenRouter 表采用精确匹配及无歧义短名；计价时去除末尾 `-basispoints`，界面保留原始名称。其他未确认别名显示未定价，公开免费型号保留零价格。
- **计价范围**：按获取时的 OpenRouter 美元基础文本 Token 单价估算；不含长上下文阶梯价、工具等附加费及历史价格变化。手工价格表及 `plans.json` 保留兼容。

## 设置与网络

- 设置页改为圆角分组、右侧开关、二级详细设置和底部语言切换，完善中英文及深浅主题。
- 软件更新检查明确指向 VibeGauge GitHub Releases。
- 新增 Clash／Mihomo 控制器密钥输入、保存、删除和测试；按控制器地址分别使用 Windows DPAPI 加密保存。
- 支持局域网 OpenClash／Mihomo 软路由控制器，可按来源设备 IP 过滤。局域网控制器使用自己的已保存密钥；环境变量回退只用于本机控制器。
- Claude、ChatGPT／Codex、OpenAI API 分别进行公开 trace 探测；Gemini 使用控制器活动连接链，明确区分无活动连接、认证失败和网络失败。
- 出口比较区分无有效结果、仅一个结果、相同及不同出口；成功的 IP／地区基准持续保存，失败不会覆盖，手动与定时诊断使用同一服务。

## 行为修复与内存

- Claude 额度从多个有效来源择新，损坏来源回退；缺采集时间时按文件时间判断新鲜度。
- API 日志保留主机和账号元数据，兼容旧发送字段；重放补充元数据时避免重复 Token 和调用计数。
- 修复滚动套餐窗口说明、无效模型子池、限流响应快照与账号隔离，以及供应商业务错误判断。
- 阈值通知增加稳定基线、升级和重新布防，减少重复提醒；补齐动态英文文案。
- MCP 清理保护有活动子进程的候选，保护信息读取失败时跳过，执行前再次复核目标；回归使用合成进程，不终止真实用户进程。
- Claude 压缩事件按 UUID 去重，并保留压缩前后 Token 明细；完善原生 Ark 程序发现。
- 复用未变化来源的去重记录、共享重复字符串，隐藏窗口暂停详情控件重建；五秒后台刷新、历史范围和已有功能保持。
- 两轮合成 UI 测试平均私有工作集降低约 6～7 MiB，无变化用量扫描分配减少约 74%。这些结果不代表真实环境必然从 150 MB 降至 100 MB。

## 升级与验证

1. 升级前退出旧版 VibeGauge 及其代理，保留 `%LOCALAPPDATA%\VibeGauge` 中的配置和账本。
2. 正常运行安装版或免安装版会沿用已有数据；此次不向公共安装包打入个人价格表、控制器密钥或用户日志。
3. 使用 OpenRouter 计价时，点击更新按钮获取公开价格；安装包不预置固定时点价格。
4. Gemini 连接链需要可达的控制器、正确密钥及实际活动连接。trace 展示诊断请求的网络路径，客户端独立代理路径需结合连接链判断。

本地正式版参数回归 **437 项通过**：Core 285、Proxy 26、Windows 126。覆盖统计范围、折叠与来源汇总、计价单位与别名、控制器认证、来源设备过滤、失败网络、通知、旧账本迁移及界面渲染。发布包执行主程序与代理自检；GitHub 在 macOS 和 Windows 构建成功、附件上传完成后发布正式版。

开发阶段的证据与边界见[重新审计修复](https://github.com/Fourgetu/vibe-gauge/blob/v1.6.5/docs/windows-upstream-reaudit-fixes-2026-09-30.md)、[软路由控制器](https://github.com/Fourgetu/vibe-gauge/blob/v1.6.5/docs/windows-router-controller-2026-09-30.md)、[统计页与 Agent 用量](https://github.com/Fourgetu/vibe-gauge/blob/v1.6.5/docs/windows-statistics-agents-2026-09-30.md)、[OpenRouter 计价](https://github.com/Fourgetu/vibe-gauge/blob/v1.6.5/docs/windows-openrouter-prices-2026-09-30.md)及[内存复测](https://github.com/Fourgetu/vibe-gauge/blob/v1.6.5/docs/windows-memory-2026-09-30.md)。合成回归不替代真实供应商账号、路由器和跨系统端到端验收。
