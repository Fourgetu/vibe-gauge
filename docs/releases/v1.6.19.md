# VibeGauge v1.6.19

本版重构 Windows 的 Claude 订阅额度获取方式，移除桌面端本地凭据解密，改为更安全、可控的可选来源。

- **彻底移除 Claude Desktop 凭据解密**：不再读取或通过 DPAPI / AES-GCM 解密桌面端 `Local State` 中的 `oauth:tokenCacheV2`，降低 Windows 杀毒软件误报与服务条款风险。
- **新增「系统 → 详细设置 → Claude 额度来源」配置页**：
  - **仅本地（默认）**：仅读取桌面真实用量账本与运行状态，不发起在线额度查询，并保留浏览器一键打开官方用量页（`claude.ai/settings/usage`）。
  - **Web sessionKey（无需安装 Claude Code）**：支持手动粘贴 `claude.ai` 的 `sessionKey` 或完整 Cookie 头，仅存入 Windows 凭据管理器，提供连接测试；遇到 Cloudflare 验证时自动停止并保留上次快照，不尝试绕过。
  - **Claude Code OAuth**：按需读取明文 `~/.claude/.credentials.json` 并校验 `user:profile` 权限。
- **优化轮询与限流退避**：Claude 在线额度自动查询调整为每 3 分钟一次，遇 HTTP 429 或 Cloudflare 自动指数退避（最长 30 分钟），手动刷新仍可立即重试。

macOS 功能不变。
