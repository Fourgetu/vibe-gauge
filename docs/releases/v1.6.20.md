# VibeGauge v1.6.20

本版移除独立的 `Claude Desktop` 卡片，将所有 Claude 本地用量与官方额度来源统一合并到 `Claude` 卡片。

- **移除 `Claude Desktop` 卡片与列表项**：不再在订阅卡片、客户端显示列表和今日用量来源中单独列出 `Claude Desktop`；桌面端 `</>` Code 模式写入的 `~/.claude/projects/*.jsonl` 仍完整统计在 `Claude` 下。
- **统一 `Claude` 卡片的额度来源**：在「系统 → 详细设置 → Claude 额度来源」启用的 `Claude Code OAuth` 或 `Web sessionKey` 实时额度（每 3 分钟查询、遇 429 自动退避）现在直接展示在 `Claude` 卡片上；若同时开启了状态栏额度连接（`claude-usage.json`），则自动优先保留较新的官方额度快照。
- **优化状态提示**：当 `Claude` 卡片处于查询中或凭据失效状态时，卡片与悬浮提示直接展示具体原因，避免被泛化为「未检测到额度」或「读取失败」。

macOS 功能不变。
