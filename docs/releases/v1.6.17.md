# VibeGauge v1.6.17

大幅优化 Windows 版常驻运行内存占用与安装包体积。

- **后台内存大幅降低**：
  - 启用 `.NET 10` 低内存 GC 配置（`System.GC.ConserveMemory=9`）与 WPF 软件渲染模式（保持 Win11 原生亚克力/云母毛玻璃不变，可通过 `VIBEGAUGE_RENDER_MODE=hardware` 切回），并在启动后自动整理托管堆。
  - 将**贴顶自动收起**与**隐藏到托盘**统一纳入后台低功耗态：收起后暂停 1 秒快速刷新、后台全量扫描自动降频至 30 秒、停止不可见界面重建，并在 5 秒后压缩 LOH 与释放闲置工作集；再次展开或鼠标移至顶边时即时恢复刷新。
  - 历史用量扫描器（`UsageScanner`）在日志、价格表与日期无变化时直接复用上次统计快照，避免每 5 秒重复解析与重算；系统扫描按需懒加载计划任务与端口保护信息，并将页面文件查询改为 30 秒缓存。
- **安装包体积瘦身 ~31%**：
  - 将本地记账代理 `VibeGauge.Proxy.exe` 全部 JSON 序列化迁移为源生成（零反射）并开启 `PublishTrimmed=true` + `TrimMode=full`，代理本体从 ~102 MB 缩减至 ~20.7 MB（-80%），Windows 安装包由 ~81 MB 降至 ~56 MB、便携 ZIP 由 ~116 MB 降至 ~79 MB，同时保持 100% 兼容现有状态栏桥接、观察钩子与 HTTP 代理功能。

macOS 功能不变。Windows 安装包、免安装版及 macOS 压缩包均附 SHA-256 校验文件。
