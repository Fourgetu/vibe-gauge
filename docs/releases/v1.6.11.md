# VibeGauge v1.6.11

Windows 版新增 Devin Token 统计，并修复 Claude Desktop 登录识别，加入官方额度监控和本地用量统计。

## Windows

- 新增 Devin 今日、累计及每日模型用量；可在系统页选择是否显示 Devin 卡片。只统计本地数据库中有用量记录的回复，按会话和消息 ID 去重，缓存不重复计入总 Token。删除会话不会清除已采集的历史；未落盘的云端用量不计入。
- 接入 Claude Desktop 本地真实 Token 账本，支持已写入账本的 Chat、Cowork 和 Code 活动；展示输入、输出、缓存与已记录会话累计值，不估算上下文占用。
- 没有本地账本的云端聊天／远程会话仍不可统计；Claude Desktop 真实账号的本地账本读取尚未完成端到端验证。详见覆盖边界说明。
- 独立识别 Claude Desktop 和 Claude Code，桌面后台子进程不再被误计为 Code 会话。支持经典版、商店版和自定义配置目录。
- 识别当前桌面配置的登录状态；无法确认时显示未知，不再仅凭旧账号记录推断已登录。
- 新增 Claude Desktop 官方额度监控，展示套餐、5 小时与每周额度、重置倒计时和额外模型额度池；每 60 秒自动刷新，支持手动刷新。
- 网络失败保留并标记当前账号的上次数据；切换账号、组织或配置目录时隔离缓存、历史和在途请求。无法读取额度时不会显示虚假的零用量。
- Claude Desktop 卡片使用一行两列布局，不再独占一整行。
- 只读使用当前 Windows 用户的桌面授权缓存，查询固定的 Anthropic 官方额度接口；不读取 Cookie、不刷新或写回客户端 Token，不把 Token 写入日志或历史。

桌面授权缓存与登录标记属于客户端内部格式，已在 Claude Desktop 5.11492.5 上验证。未来格式变化时会显示未知或凭据不可用；凭据续期由 Claude Desktop 完成。详见 [Claude Desktop 使用说明](https://github.com/Fourgetu/vibe-gauge/blob/v1.6.11/docs/windows-claude-desktop.md)。

本次功能适配针对 Windows。macOS 保持原有功能；构建与发布流程迁移至 macOS 15 运行器，应用最低系统要求仍为 macOS 14。

## 验证

- Windows 568 项测试通过：Core 373、Windows 169、Proxy 26。
- 主程序与代理自检通过；真实桌面账号的官方额度查询及两列布局已验证。
- 正式发布流程执行 macOS Universal 构建和自检，以及 Windows 安装包、免安装包构建；两端完成后才公开正式版。

## English

- Track locally recorded Devin tokens by day and model, deduplicate replies, and retain observed usage after session deletion. The Devin card can be hidden in System settings.
- Fix Windows Claude Desktop login detection and distinguish desktop processes from Claude Code sessions.
- Monitor official desktop-account quotas, including plan, five-hour and weekly usage, reset countdowns and additional model pools, with automatic and manual refresh.
- Preserve clearly marked stale data on connection failures and isolate cached results when the account, organization or profile changes.
- Keep the Claude Desktop card in the two-column layout.
- Read the current Windows user's encrypted authorization cache without changing or refreshing client tokens; use only the fixed official quota endpoint.
- Verified with 568 Windows tests and executable self-tests. Official quota retrieval was verified with a live Claude Desktop 5.11492.5 account. Internal client-format changes may require future compatibility updates.
- Include Windows installer/portable packages and a macOS Universal build with unchanged macOS features and SHA-256 checksums. Move macOS CI/release runners to macOS 15 while retaining the macOS 14 deployment target.
