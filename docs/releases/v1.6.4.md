# VibeGauge v1.6.4

Windows Codex 实时额度与紧凑卡片布局修复。解决已识别 Pro 登录、但本地会话没有新额度回报时，首页和详情页一直等待的问题；同时修复 Codex 名称被套餐与会话数挤成省略号的问题。保留 v1.6.3 的账号隔离与历史 Token 账本逻辑。macOS 功能实现不变，随版本提供 Universal 构建。

## 修复与改进

- **直接查询当前账号额度**：通过本机 Codex CLI 的 App Server 查询订阅额度，不再只依赖本地会话日志。后台每 60 秒查询一次，手动刷新可立即重试；页面在后续扫描时显示查询结果。
- **只显示实际返回的窗口**：按窗口时长识别 5 小时和 7 天额度，不再根据 primary/secondary 位置猜测。服务仅返回周窗口的 Pro 账号，首页和详情页都只显示周额度；Plus／Team 返回双窗口时保留双窗口。缺失窗口不会补成零百分比。
- **保留账号隔离**：账号切换会取消旧查询并清除旧缓存；API Key 模式不继承订阅额度。查询前后校验本机登录文件更新时间，登录变化时丢弃结果。
- **明确异常状态**：CLI 缺失、超时或网络失败时显示原因；仅保留同一账号上次成功的额度并标为过期，不借用旧账号回报。
- **完整显示 Codex 标题**：紧凑卡片优先保留客户端名称和套餐标签，会话数空间不足时省略，悬停仍可查看完整信息。不加宽窗口或增加卡片高度。
- **会话计数更准确**：临时额度查询进程不再计入用户 Codex 会话数。
- **保护本地数据**：不重置历史 Token、账本或设置。额度查询不创建对话或模型请求，不在命令参数、错误信息或缓存中保存登录令牌。

## 使用与升级说明

1. 升级前退出旧版 VibeGauge 及其代理，保留 `%LOCALAPPDATA%\VibeGauge` 中的账本和设置。
2. 实时订阅额度需要可用的本机 Codex 原生 CLI，以及同一本机账号的 ChatGPT 订阅登录。支持 Codex Desktop 本地程序、npm 原生包和 PATH 中的原生程序。
3. 登录后可点刷新，等待后台查询及下一次页面扫描。网络失败时查看状态说明；不要把过期缓存当作最新回报。
4. 本次不是登录工具，也不会替用户切换账号。不同账号的窗口以服务实际返回为准，不对所有 Pro 套餐预设固定窗口。

规则与限制见[账号与刷新说明](https://github.com/Fourgetu/vibe-gauge/blob/v1.6.4/docs/windows-account-quota.md)。

## English

- Query current Codex subscription quotas through the local native App Server every 60 seconds, with manual refresh support.
- Map quota windows by their actual duration. A weekly-only response stays weekly-only in both overview and detail views.
- Preserve account isolation, cancel outdated requests, and label same-account cached results as stale after errors.
- Keep the Codex name and plan readable in compact cards; truncate optional session text first.
- Exclude the short-lived quota helper from user session counts. Retained token accounting is unchanged.
