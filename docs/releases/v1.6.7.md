# VibeGauge v1.6.7

Windows 深浅色毛玻璃与选中状态优化。浅色减少白色叠层，深色增强背景透色；顶部导航和底部语言选项统一灰底白字。macOS 随版本提供 Universal 构建。

## 界面调整

- 浅色采用轻微深色的半透明面板与卡片，拉开层次，减少白色覆盖背景的效果。
- 深色降低窗口底色的不透明度，保留背景色彩，同时调整卡片、悬停和次级文字，兼顾明亮背景下的可读性。
- 顶部导航、API 时间范围和底部语言选项的选中状态统一使用灰色底与白字。文字显式跟随控件前景色，避免被全局文字样式覆盖；悬停选中项时保留选中底色。
- 延续原生 Desktop Acrylic。透色随窗口背后的内容变化，纯色背景不会呈现彩色纹理；无法启用原生背景时继续使用实色回退。

## 升级与验证

升级前退出旧版 VibeGauge 及其代理。保留 `%LOCALAPPDATA%\VibeGauge` 中的配置和账本，安装版和免安装版继续使用原有数据。监控、计价和刷新周期保持原有行为。

本地主题及 UI 回归 4 项通过，预览主程序自检通过。使用隔离的合成数据，在彩色、纯白、纯黑背景上检查真实桌面合成效果，并验证浅色／深色往返切换后的选中标签为白字。GitHub 发布流程执行完整 Windows 测试、主程序与代理自检以及 macOS 构建与自检，成功后公开正式版。
