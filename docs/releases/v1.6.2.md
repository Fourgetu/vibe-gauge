# VibeGauge v1.6.2

Windows 客户端监控、二级详情及上游功能对齐更新。先修复 D1–D6 并通过测试，再移植选定的 A1–A3、A5、A6、A8–A15；未加入 A4、A7、A16、A17。macOS 功能实现不变，随版本提供 Universal 构建。

## 新增与改进

- **WorkBuddy / DSH Desktop**：加入本地 Token 监控与删除会话后的历史留存；系统页可选择订阅页显示哪些客户端，隐藏不会停止采集或改变总量。
- **二级详情**：客户端卡片可查看额度、用量和本地数据来源；圆环采用上游配色，保留紧凑布局、完整悬停信息及浅深色主题。
- **成本与套餐估算**：读取 `prices.json` 计算 API 等价成本，区分缓存读写和未定价模型；`plans.json` 支持加权请求、共享/模型独立池及多种重置规则。均为本机估算，不是厂商账单。
- **API 质量**：增加 p50/p95/最大延迟、429 次数、限流响应头明细，以及成功但缺少 usage 的未知用量提示。
- **Gemini / AGY 桥接**：系统页安装/恢复状态栏桥接，备份原配置并转发原状态栏输出。
- **网络诊断**：可选 AI 站点出口对比、出口变化、Clash/Mihomo 连接链、DNS/IPv6 提示和 Wi-Fi/Tailscale 状态。
- **通知与维护**：独立的待输入/审批、额度、内存、磁盘和出口提醒；按目录查看占用，确认后执行允许范围内的保留期/NPX 清理；可选保守孤儿 MCP 自动清理。
- **系统功能**：新增 Windows fork 更新检查、跟随系统/中文/英文切换，以及官方 CLI 安装登录引导。本地模型发现支持更多端口与运行中但未响应的状态。
- **历史压缩**：适用来源 90 天前的逐条热记录折叠为日/来源/模型/小时汇总，保留压缩恢复索引与去重。Claude/API 暂保留完整索引以保护原有统计规则。

## 关键修复

1. Codex 较新的明确耗尽事件覆盖旧主周额度，避免额度已经用完但仍显示旧余量。
2. Gemini 桥接和 AGY 缓存逐池、逐窗口选择较新数据，不再整份优先使用旧来源。
3. 主卡、二级详情和通知使用统一的客户端活动画像及预测回退规则。
4. API 汇总保留缺失用量和完成状态元数据，不把未回报 usage 当成实测零。
5. 预测通知在停用、恢复及超过 120 秒未观察后重计稳定时长，保留通知去重。
6. LM Studio 区分可用模型与已加载实例，不再把普通模型列表当成已加载数量。

## 升级与安全说明

- **升级前退出旧版及其代理，保留 `%LOCALAPPDATA%\VibeGauge` 的设置与账本。**不要为升级清空用量数据。
- 新版首次读取旧 `usage-incremental.json` 后独立写入 `usage-ledger-v2.json`，原账本保留。旧版与新版账本不双向同步，避免反复交替使用两版；回退时保留两个账本，特别是在源会话已删除的情况下。
- 新增自动清理、外部网络诊断、通知类别及更新轮询默认关闭。不会自动删除会话文件；手动清理需要预览/确认，且先确保用量账本落盘。
- 自动 MCP 清理需要当前用户归属、重复观察及稳定时间等校验；未在真实用户进程上进行破坏性测试。
- 网络诊断会在用户启用后访问公开诊断端点，不发送 API Key 或用量日志。Clash 认证通过环境变量提供，不保存到配置或界面。
- 价格及套餐限额需要自行配置；没有预填假价格。完整 JSON 字段、默认行为、迁移边界见[功能与配置说明](https://github.com/Fourgetu/vibe-gauge/blob/v1.6.2/docs/windows-parity-implementation.md)。
