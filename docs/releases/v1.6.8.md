# VibeGauge v1.6.8

Windows 毛玻璃控制与失焦显示优化。

## Windows

- 系统页新增“毛玻璃透明度”滑块，可实时调整背景通透程度。
- 浅色与深色分别保存透明度设置，切换主题、重新打开窗口后保留。
- 透明度只作用于窗口背景，不会把文字、卡片内容或控件一起变淡。
- 窗口失去焦点、切换到其他程序或重新打开后继续保持 Desktop Acrylic 毛玻璃效果。
- 固定窗口、自动收起、外部程序焦点切换和深浅色切换保持原有行为。
- 系统页透明度控件补齐英文界面。

## 验证

本地完成主程序自检、透明度设置持久化测试、主题切换测试、滑块交互测试，以及激活／失焦／重新打开／外部程序焦点切换的桌面合成检查。正式发布流程会继续执行完整 Windows 测试、代理自检和 macOS Universal 构建。

## English

- Add a System page slider for live glass transparency adjustment.
- Save light and dark transparency preferences independently across theme changes and relaunches.
- Keep text, cards and controls opaque while changing only the window backdrop.
- Keep Desktop Acrylic visible when the window loses focus, another app is active, or the window is reopened.
- Preserve pinning, auto-hide, focus transfer and theme switching behavior.
- Include Windows installer/portable packages and a macOS Universal build with SHA-256 checksums.
