# VibeGauge v1.5.2

Windows 历史用量保留修复与系统页版本号更新。保留既有界面、毛玻璃主题、紧凑布局、贴顶收缩及轻量化优化；macOS 功能实现不变，随版本提供 Universal 构建。

## 修复与改进

- **删除会话不再扣减已记录用量**：将 v1.5.1 的 PI-Desktop 修复扩展至 Claude Code、Codex；今日总量、来源卡片、最近调用、日期/模型统计和历史使用一致的保留记录，重启后仍有效。
- **Codex 归档与恢复去重**：同时识别 `sessions` 和 `archived_sessions`，按会话标识合并日志副本；不同会话即使用量和时间相同，也不会混为一条。
- **日志重写保留历史**：Claude/PI 按消息标识保留记录；Codex/API 匹配已观察事件，避免日志清空后分批恢复、重读和重启造成重复累计。API 日志迁移也不会重复加入相同记录。
- **系统页显示当前版本**：在“系统资源”标题右侧显示 `VibeGauge v1.5.2`。版本来自正在运行的程序，后续升级自动更新显示，不依赖网络或写死的界面文本。

## 升级与统计边界

- 兼容现有统计缓存。升级后可能重新显示此前遗漏的缓存或归档用量；数字增加不代表新增消费。
- 不修改源会话文件，不恢复聊天正文或附件。请保留 `%LOCALAPPDATA%\VibeGauge` 中的配置与统计缓存；从未记录或已从缓存移除的用量不能恢复。
- API 与 CLI 继续独立记账。本次不更改 Token 字段口径，也不代表已完成与第三方账单的对账；详细去重与保留边界见[历史用量说明](https://github.com/Fourgetu/vibe-gauge/blob/v1.5.2/docs/windows-usage-retention.md)。
- 保留五秒刷新与既有功能，不新增网络服务。已有 Codex 日志首次升级时补读会话标识，后续恢复增量扫描。

## 验证

- Windows **201 项自动化测试**，覆盖 Core、Proxy 和 Windows 界面逻辑，其中新增删除/恢复/归档保留及版本号相关回归测试。
- 系统页深浅色原生截图核验；发布流程在 macOS 和 Windows 构建、自测、附件上传均成功后才发布正式版。
- 升级前完成正在转发的 API 请求，再退出旧版托盘程序。便携版请完整解压；清理旧安装包时不要删除正在使用的安装目录或统计缓存。
- Windows 安装包暂未代码签名，可能出现 SmartScreen 或未知发布者提示，请核对来源和 SHA-256。

## English Summary

- Retain observed Claude Code, Codex, PI-Desktop, and separate API consumption after source deletion and log rewrites.
- Recognize archived Codex sessions and avoid double-counting restored copies, partial replays, and migrated API logs.
- Display the running application version on the System page, without a hardcoded version or network lookup.
- Keep existing token interpretation, refresh cadence, configuration, and retained history. Unobserved or removed cache history cannot be reconstructed.
