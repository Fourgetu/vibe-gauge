# VibeGauge v1.6.6

Windows 网络页简化、DNS/IPv6 体检、今日按项目用量和独立轻量刷新正式发布。保留原有 Agent 用量、历史统计及 OpenRouter 计价。macOS 实现保持不变，随版本提供 Universal 构建。

## 网络

- 网络页采用 AI 出口、代理内核、本地网络和网络体检卡片。代理组默认精简展示，全部连接、网卡和诊断明细可展开，刷新保留展开状态。
- 保留 Claude、ChatGPT/Codex、OpenAI API 的独立出口探测、Cloudflare 对照以及 Gemini 活动连接链。
- DNS 区分国内公共 DNS 警告、Fake-IP 代理接管特征和未知。本地/路由器 DNS 不会直接被判为安全或泄漏。
- IPv6 强制使用 IPv6 socket，并同时执行 IPv4 对照。收到 HTTP 响应即视为可达；只有 IPv4 可达且 IPv6 解析、连接或超时失败时，才显示“本次未发现直连”。断网和 TLS 等错误显示未知。
- 探测禁用系统 HTTP 代理，但仍受系统路由、TUN 和软路由策略影响；结果不证明所有客户端或目标都走相同路径。

## 今日按项目

- 订阅页按 Claude/Codex 日志的工作目录合并今日用量，默认前三项，可展开全部。原有每 Agent 用量与 Live 记录保留。
- 显示项目名称、上下文 Token、贡献客户端和交互次数。上下文包含缓存；条形相对于最大项目，不是占总量的百分比。完整路径可悬停查看，同名目录分别统计。
- 旧账本补读现存日志的项目元数据，保持去重和历史消耗总量；缺失路径归入“未知项目”，不猜测已删除日志的目录。首次升级可能有一次补读开销。

## 刷新与开销

- 订阅页可见时，客户端进程状态约每秒更新；网络页可见时，速率约每秒更新。隐藏窗口和其他页面停止这条轻量任务。
- 轻量路径不调用日志扫描、WMI、额度请求或清理策略。网络速率复用现有控件，迟到结果不会覆盖切页、隐藏或退出后的状态。
- 日志、会话明细和完整系统扫描保持约 5 秒。新启动、仅能靠命令行识别的 node CLI 仍由常规扫描发现。
- Codex 官方额度保持 60 秒；OpenRouter、DeepSeek、GLM、MiniMax 和自定义站点额度改为 3 分钟。完整网络诊断在开启自动检测时为 5 分钟，保留手动刷新。
- 短时合成测试中，私有提交内存中位数与改动前接近，CPU 和分配略有增加，末次内存仍有波动。这不代表真实使用能稳定在 100 MB，也不是任务管理器“专用工作集”的测量。

## 升级与验证

升级前退出旧版 VibeGauge 及其代理，保留 `%LOCALAPPDATA%\VibeGauge` 中的配置和账本；安装版和免安装版继续使用原有数据。发布包不包含个人密钥、价格表或用户日志。

本地回归 **462 项通过**：Core 305、Proxy 26、Windows 131。覆盖项目归并、复制/归档日志、旧缓存迁移、跨日范围、未知路径、DNS/IPv6 判定、刷新并发和过期结果、进程身份，以及中英文、深浅色和窄窗口 UI。主程序和代理自检通过。GitHub 发布流程再次运行测试，构建安装包及 ZIP，全部成功后公开正式版。

完整证据和测量边界见 [Windows 功能补齐报告](https://github.com/Fourgetu/vibe-gauge/blob/v1.6.6/docs/windows-parity-2026-10-01.md)。合成测试不替代真实账号、软路由和各网络环境的端到端验证。

## English

- Simplify network cards and retain expandable proxy, adapter and diagnostic details. Add conservative DNS/IPv6 checks that distinguish warnings, unavailable routes and unknown results; offline or TLS failures are never treated as a pass.
- Add daily Claude/Codex usage by project, with three entries by default and full expansion. Preserve independent agent usage, enrich legacy records without duplicate consumption, and leave missing paths explicitly unknown.
- Refresh visible process status and network rates about once per second through a separate lightweight path. Keep log/session scans at five seconds, Codex quotas at one minute, other official/custom quotas at three minutes, and opt-in network diagnostics at five minutes.
- Validate 462 local regression tests plus application/proxy self-tests. Synthetic memory results do not establish a sustained 100 MB target in real use.
- Include Windows installer/portable packages and a macOS Universal build, each with SHA-256 checksums.
