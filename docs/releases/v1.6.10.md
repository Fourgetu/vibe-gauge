# VibeGauge v1.6.10

Windows 新增 Codex Proxy RS 服务端用量与额度监控。

## Windows

- API 页底部的「额度监控 · API 密钥」新增 **Codex Proxy RS**。填写部署地址和客户端 API Key，可先测试连接再保存，无需管理员密码。
- 每 3 分钟同步日/周额度，以及今日、近 30 天、已同步累计 Token 和请求数。展示输入、输出、缓存、思考、近期趋势及近 30 天最近 20 次请求。
- 服务端统计覆盖当前 Key 的所有设备调用，独立于本地代理和 Codex 日志展示，避免重复计算。费用保留站点回报金额，并标注未知或不完整状态。
- 首次同步覆盖近 30 天，之后保留已同步历史；重复同步替换重叠时间段。**已同步累计不是完整历史账单**，更早历史及离线期间超出查询窗口的缺口不会自动补齐。
- 密钥保存在 Windows 凭据管理器，会话过期自动重新登录；连接失败保留并标注本次运行中上次成功数据。历史缓存不含原始密钥或会话 Cookie。
- 适配深浅色、中英文和窄窗口；支持中文/国际 Token 单位切换。

配置步骤和统计边界见 [Codex Proxy RS 使用说明](https://github.com/Fourgetu/vibe-gauge/blob/v1.6.10/docs/windows-codex-proxy-rs.md)。本次功能适配仅针对 Windows，macOS 保持原有功能。

## 验证

本地 Release 测试共 496 项通过（Core 325、Proxy 26、Windows 145），主程序与代理自检通过。覆盖接口解析、会话重登、失败保留、缓存损坏、历史去重和界面交互。适配基于 Codex Proxy RS v3.35.1 接口，使用模拟接口验证，尚未连接用户的实际部署；不同部署版本可能需要进一步兼容。正式发布流程另外执行 Windows 安装包构建与 macOS Universal 构建及自检。

## English

- Add Windows Codex Proxy RS monitoring using a deployment URL and client API key, with a connection test and Windows Credential Manager storage.
- Refresh quotas and separate server usage every three minutes, including today, last 30 days, synced totals, token details, trends and recent requests.
- Keep server costs and usage separate from local estimates and logs. Initial history covers 30 days; synced totals are not a complete lifetime invoice.
- Recover expired sessions, preserve clearly marked stale results on connection errors, and safely replace overlapping history.
- Verified with 496 local tests and both executable self-tests. Contract fixtures target Codex Proxy RS v3.35.1; the user's live deployment has not been verified.
- Include Windows installer/portable packages and an unchanged-feature macOS Universal build, with SHA-256 checksums.
