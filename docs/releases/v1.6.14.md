# VibeGauge v1.6.14

Windows 新增 Antigravity 监控，并修正此前预览版的缓存统计。

- 用量：从本地会话记录统计每日、累计及各模型的 Token，并在会话页展示近期活动。已经采集的用量不会因为删除原会话而消失。
- 订阅：通过已登录的官方 agy CLI 后台读取账号套餐、可用的 5 小时和每周额度，无需打开 Models 页。额度不可用不影响本地 Token 统计。
- 缓存：修复 Antigravity 缓存读取计入分子却漏计总输入的问题。缓存占比按缓存读取 Token ÷ 全部输入 Token 计算；旧预览版的留存记录会自动修正，无需清除历史。其他客户端的计数口径不变。

macOS 功能不变。Windows 安装包、免安装版及 macOS 压缩包均附 SHA-256 校验文件。
