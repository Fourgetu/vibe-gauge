# VibeGauge v1.6.9

Windows Codex 用量展示与 OpenAI 官方运行状态监控。

## Windows

- Codex 检测到 API Key 模式时，概览卡片显示今日与累计 Token 用量；切回账号登录后恢复额度圆环。
- 用量复用本地日志统计，包含归档会话与压缩保留的历史，并对重复日志去重。累计值包含账号与 API 两种模式的历史，不代表 API 账单。
- 保留账号切换时的额度隔离，API 模式不会沿用旧订阅额度；认证信息读取失败时明确提示。
- 网络页底部新增 OpenAI 官方运行状态：服务分组、组件数量、官方可用率和近 90 天状态条。可展开组件，悬停查看每日故障信息。
- 状态页使用原生 WPF 控件，无需嵌入浏览器或配置 API 密钥。网络页可见时每 3 分钟查询，支持手动刷新；查询失败保留并标注上次成功数据。
- 状态展示适配深浅色、窄窗口与中英文界面。官方全局状态与本机网络连通性分别展示。

## 验证

本地 474 项测试通过（Core 314、Proxy 26、Windows 134），并通过主程序与代理自检。覆盖登录模式切换、日志归档与去重、压缩历史累计、跨天故障、官方页面格式变化、查询失败及界面布局。已验证官方页面实时数据读取。正式发布流程另外执行 Windows 安装包构建与 macOS Universal 构建及自检。

## English

- Show today's and cumulative local Codex tokens in API-key mode; restore quota rings for account login.
- Include deduplicated archived and compacted history. Local totals include both authentication modes and are not an API invoice.
- Preserve account-scoped quota isolation and explicit authentication-read errors.
- Add native OpenAI service-status groups, component details, official uptime and 90-day incident history at the bottom of the Network page.
- Refresh every three minutes while visible, with manual refresh and clearly marked stale data after failures. No embedded browser or API key is required.
- Include Windows installer/portable packages and a macOS Universal build with SHA-256 checksums.
