# VibeGauge v1.5.1

Windows PI-Desktop 用量保留修复。保留 v1.5.0 的总 Token 展示、紧凑布局、浅深色毛玻璃、贴顶收缩及轻量化优化；macOS 功能实现不变，随版本提供 Universal 构建。

## 修复内容

- **删除对话不再扣除已记录的用量**：删除 PI-Desktop 对话或整个 sessions 目录后，今日总量、来源卡片、近期调用、模型分布、日历和本地累计用量继续使用保留的统计记录。
- **日志重写与重启后仍保留历史**：清空、截断、重写日志或在同一路径新建对话时，仅重置读取游标，已完成调用的记录不会被一并清除。
- **恢复或复制对话不重复计数**：同一消息 ID 仍只统计一次；同一消息的修正用量更新原记录，不增加调用次数。删除带有修正记录的文件后，也不会退回旧值。
- **兼容现有缓存**：升级后可以重新显示现有 version-1 缓存中保留、但此前因源文件被删除而未显示的用量。因此数字可能增加，这表示找回已记录的历史，不是新增消费。

## 数据与统计边界

- 仅保留用量元数据，不恢复或保存已删除的聊天正文、附件，不修改 PI-Desktop 文件、密钥或代理设置。
- 删除 VibeGauge 自身的统计缓存仍会丢失其中的历史。VibeGauge 从未记录过、或缓存中已不存在的用量无法恢复。
- 本次仅修复历史保留，不调整 Token 字段解释、缓存与思考 Token 的计算口径，也不将独立 API 统计混入 PI-Desktop。与第三方账单的核对仍需匹配相同时间、账户及计数口径。
- 保留五秒刷新频率与既有监控功能，不新增运行时、数据库驱动或网络服务。

## 升级与验证

- 升级前完成正在转发的 API 请求，再退出旧版托盘程序。安装器不会强制结束旧进程；便携版请完整解压。
- 保留 `%LOCALAPPDATA%\VibeGauge` 中的配置和统计缓存；密钥仍存于 Windows 凭据管理器。
- Windows **176 项自动化测试**覆盖 Core、Proxy 和 Windows 界面逻辑，新增六项回归测试验证删除、重写、重启、恢复去重和修正记录；同时调整原日志重写测试以验证历史保留。
- 发布流程在 macOS 和 Windows 构建、自测及附件上传成功后才发布正式版。
- Windows 安装包暂未代码签名，可能出现 SmartScreen 或未知发布者提示；请核对仓库来源和 SHA-256。

## English Summary

- Preserve previously recorded PI-Desktop consumption after conversation deletion, sessions-directory removal, log truncation or rewriting, and application restarts.
- Deduplicate restored or copied message IDs and retain corrected usage without adding another call or reverting after source deletion.
- Reuse existing cached usage metadata without restoring conversation content. History never observed or no longer present in the cache cannot be recovered.
- Keep token-field interpretation, separate API accounting, the five-second refresh interval, and all v1.5.0 features unchanged.
