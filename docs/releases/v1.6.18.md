# VibeGauge v1.6.18

本版修复 Windows 的 Antigravity 额度显示、Claude 模型名称和 OpenRouter 成本估算。

- Antigravity 明确回报剩余 100%、并以 Unix 时间零点作为重置时间时，显示满额并将重置时间视为未知。真实过期、禁用或未回报的窗口不会显示成满额。
- Live 与模型详情保留 Claude Opus 5 的小版本和思考等级，例如 `Claude Opus 5.5 Medium` 和 `Claude Opus 5.5 High`。
- Devin、Antigravity 等客户端带思考等级的模型名可匹配 OpenRouter 基础模型单价；独立定价的变体优先，匹配有歧义时保留“未定价”。
- `cn:deepseek-v4.1-flash` 可按 `deepseek/deepseek-v4.1-flash` 估算，沿用当前价目表，历史用量无需重新采集。统计显示的是 API 等价成本，不是订阅账单。

macOS 功能不变。
