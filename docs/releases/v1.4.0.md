# VibeGauge v1.4.0

首个 Windows 正式版，包含此前基于上游 v1.3.1 的移植及全部后续功能修正。macOS 保留上游实现，并提供 Universal 安装文件。

## Windows 新功能与修复

- 原生 WPF 托盘应用，支持窗口拖动、边缘缩放、固定显示与窗口位置记忆。
- Windows 11 毛玻璃外观，支持浅色/深色切换并保存偏好；修正文字、悬浮提示和输入框的可读性。
- 统一细滚动条：3 像素视觉宽度，8 像素交互区域，保留拖动、翻页、横向滚动及下拉列表滚动。
- PI-Desktop 消耗监控替换原来的 Grok 项，显示本地可识别的调用与 token 用量。
- 日期联动统计：点击日历某一天，展示该日总用量和模型分布；无数据的日期显示空状态，不回退到今天。
- 自定义 sub2api 额度监控：站点名称、地址、API Key、连接测试及保存；显示站点报告的余额、用量和套餐额度。
- 保留官方厂商额度查询、Claude/Codex 会话上下文、额度可信度与预测、可选通知与 Claude 观察桥接。
- 独立 API 记账代理，支持常见 JSON/SSE 用量响应、本地日志、按厂商和模型聚合，以及明确的转发安全边界。
- 本机网络状态、本地模型与系统资源监控。

## 使用与升级说明

- 升级前先完成正在通过 VibeGauge 转发的请求，再退出旧版托盘程序。安装器不会强制终止旧进程。
- 原有配置和统计保留在 `%LOCALAPPDATA%\VibeGauge`，已登记的官方密钥继续使用 Windows 凭据管理器。
- 添加 sub2api：在 **API → 额度监控 → 自定义 · sub2api** 中输入自己的站点地址和密钥，测试连接后保存，在 **订阅** 页查看额度。站点必须提供兼容的 `/v1/usage` 接口；不承诺所有中转站都支持。
- 新密钥只发送到明确填写的站点，不跟随重定向；远程地址要求 HTTPS，本机回环地址可用 HTTP。不会将现有官方密钥自动迁移到自定义地址。
- 远程余额、套餐额度与 API Key 用量以站点返回为准，不与本地统计重复相加，不填造缺失额度或重置时间。

## 验证与已知边界

- Windows 自动化测试覆盖核心统计、日期选择、PI-Desktop、代理协议与安全、sub2api 解析与错误处理、深浅色界面、滚动操作及凭据隔离。
- 发布流水线运行 Windows 测试和已打包程序自测，以及 macOS 编译和主程序/代理/statusline 自测；两端完成并上传附件后才发布为正式版。
- Windows 安装包暂未代码签名，可能出现 SmartScreen 或未知发布者提示；请核对仓库来源及 SHA-256。
- 毛玻璃依赖 Windows 支持；关闭透明效果、远程桌面或不支持的系统会回退到可读的实色背景。
- Windows 正式发布不代表全部 macOS 功能已对齐。双语 UI、自动更新提示、远程 SSH 额度采集等仍未移植，详见 [平台边界](https://github.com/Fourgetu/vibe-gauge/blob/v1.4.0/docs/windows-upstream-1.3.1.md)。
- 真实账户和自定义站点需要用户自行测试连接；自动化测试不使用真实 API Key。
