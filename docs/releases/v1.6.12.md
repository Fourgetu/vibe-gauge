# VibeGauge v1.6.12

Windows 的 Devin 订阅卡片现在会同时显示周额度已用比例、今日和累计 Token。悬停或进入详情页可查看重置倒计时。

- 周额度来自 Devin 桌面客户端为当前登录账号保存的套餐数据，不用本地 Token 总数推算，也不需要填写 API Key。
- 切换账号不会沿用上一个账号的额度。退出登录、客户端隐藏周额度、重置时间已过或缓存不可用时，不显示旧百分比或虚假的 0%；已采集的本地 Token 历史仍然保留。
- 此次更新不改变 macOS 功能。Windows 安装版、免安装版和 macOS 压缩包均附 SHA-256 校验文件。

## English

The Windows Devin card now shows weekly quota usage alongside local token totals. Hover over the card or open its details to see the reset countdown. Quota comes from the active account's desktop cache, not a token-based estimate. Expired, hidden or unavailable quotas are omitted without affecting recorded token usage.
