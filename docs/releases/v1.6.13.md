# VibeGauge v1.6.13

Windows 版为 10 个 Devin 模型档位补上 API 等价成本估算。已有本地用量也会按当前价目表重算，无需重新采集。

- GPT-6 Astra、Sol、Luna 的 Medium Thinking；Gemini 4 Carbon Medium、Gemini 3.8 Flash Medium；Kimi K3.1 Pro Max、GLM-5.3 Max；Claude Sonnet 5.5 Medium；Claude Fable 5.2 Medium 和 Max。
- 优先使用档位自己的精确价格。如果没有，才按已确认的基础模型费率计算，并标明「按基础模型估算」。无适用价格时仍显示未定价。
- 模型名称和档位保持独立。这些映射仅用于 Devin 本地记录，不会给其他客户端或同名代理请求套价。金额非实际账单，不改变周额度或 Token 统计。

macOS 功能不变。Windows 安装版、免安装版和 macOS 压缩包均附 SHA-256 校验文件。

## English

Windows now estimates API-equivalent costs for ten Devin model variants, including existing usage history. Exact variant prices take precedence; supported variants without an exact price use the corresponding base model rate and are labeled as estimates. The mapping applies only to local Devin records, not to other clients or proxy traffic.
