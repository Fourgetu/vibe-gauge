# VibeGauge v1.6.16

全面优化 Windows 11 外观质感、白雾玻璃文字清晰度、原生交互组件、任务栏托盘图标与统计页展示。

- **外观与材质**：新增「跟随系统 / 深色 / 浅色」主题切换（实时响应 Windows 系统深浅色变化）以及「亚克力 / 云母 / 纯色」三种窗口材质选项；保留白雾毛玻璃卡片层次并启用 Win11 原生 1px 硬件圆角边框与卡片细描边。
- **清晰度与排版**：全局启用 `Display` 像素对齐文字渲染与 `Tabular` 等宽数字，调优深色白雾玻璃上的柔白三级字色、半透明深色徽章胶囊与暗槽进度条；全站图标升级为 `Segoe Fluent Icons`（Win10 自动回退）。
- **Win11 原生控件与炫酷托盘图标**：用自绘深/浅毛玻璃 WPF 托盘右键菜单与毛玻璃弹窗替代传统 WinForms / Win32 控件；新增底部轻量复制 Toast；重做 1:1 像素对齐的多 DPI 赛博霓虹 HUD 任务栏托盘图标（含实时底部霓虹进度条与柔和底光）；系统页开关升级为半透明磨砂玻璃样式。
- **页面精修**：订阅页可点击卡片增加悬停/按压反馈、加宽额度进度条并优化项目用量排版；统计页月历与按小时热力图卡片化并升级为 5 阶翠绿色阶与图例，**模型构成默认展示前 4 个模型**，其余折叠可一键展开；网络页与 OpenAI 状态页统一折叠面板和主题语义色。

macOS 功能不变。Windows 安装包、免安装版及 macOS 压缩包均附 SHA-256 校验文件。
