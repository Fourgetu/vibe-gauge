# VibeGauge v1.6.1

Windows 新增 Token 显示单位开关。保留 v1.6.0 的 ZCode 监控、紧凑卡片、历史用量保留、系统页版本号、浅深色毛玻璃及贴顶收缩功能。macOS 功能实现不变，随版本提供 Universal 构建。

## 新增与改进

- **系统页切换单位**：在资源卡片上方的「Token 显示单位」中切换 万 / 亿（默认）或 K / M / B。
- **按数量自动缩写**：国际单位采用十进制，1 K = 1,000 Token，1 M = 1,000,000 Token，1 B = 1,000,000,000 Token；不足 1 M 且达到 1,000 的数量显示 K，不足 1,000 保留整数。这是 Token 数量单位，不是存储容量 MB。
- **全局即时生效**：订阅卡片、桌面总量、近期调用、会话上下文、所选日期与模型统计、日历提示、API 页面和自定义供应商摘要同步切换，无需等待下次扫描或重新查询接口。
- **重启记忆选择**：设置独立保存在 `%LOCALAPPDATA%\VibeGauge\token-display.json`，不覆盖主题、代理、窗口位置或历史用量设置；配置缺失或无效时使用 万 / 亿。
- **保留精确统计**：只改变展示格式，原始 Token 数值、计费口径、当前统计日期和小时视图不变；悬停仍可查看精确总量及供应商原始明细。系统内存与磁盘的 MB / GB 不受影响。

## 下载与升级

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows 11 x64 | `VibeGauge-Setup-v1.6.1.exe` | 当前用户安装包，无需预装 .NET 或 Python |
| Windows 11 x64 | `VibeGauge-Windows-x64-v1.6.1.zip` | 免安装版，主程序与代理程序需放在同一目录 |
| macOS 14+ | `VibeGauge.zip` | Universal 构建 |

每个安装包/压缩包均提供 `.sha256` 校验文件。Windows 包尚未代码签名，可能触发 SmartScreen 或未知发布者提示。升级时保留 `%LOCALAPPDATA%\VibeGauge`，不要清空其中的用量缓存和设置。
