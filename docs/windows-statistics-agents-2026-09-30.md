# 统计页模型折叠与 Agent 用量（2026-09-30）

本轮补充上一轮统计页展示，按用户反馈调整两点。

## 模型构成

- 默认只展示按总 Token 排序的前两个模型。
- 超过两个模型时显示“显示全部 N 个模型”；展开后可以“收起为前 2 个模型”。不超过两个时不显示多余按钮。
- 顶部堆叠条始终包含全部模型，行内百分比始终以所选范围的全部 Token 为分母，折叠不会重新归一化为前两名的占比。
- 展开状态在当前面板的刷新、主题和单位切换期间保留，不写入用户配置。
- 点击展开只重建模型明细列表，四卡、日历和 Agent 区保留；收起后定位回模型标题。

## Agent 用量

对照上游 `Sources/StatsTabView.swift` 的 `providers` 和 `providerCard`，将工具消耗恢复为独立区域。上一轮跨来源合并同名模型后，仅在提示中保留来源不够直观。

- 每个有记录的 Agent 单独一张卡片，显示总 Token、占整体用量的百分比、调用次数、输入、输出、缓存读取、缓存写入、思考及本地价格表估算成本。
- 按来源汇总未合并的模型记录，同名模型分别归入各自工具；例如 Claude 和 Codex 使用同一模型，仍然有各自独立消耗。
- 日期范围和点选历史日与顶部卡片一致；各 Agent 的 Token 与调用数之和等于对应统计总数。
- 模型折叠不影响 Agent 卡片；所有有记录的 Agent 保持展示。
- API 代理用量延续原有独立记账口径，不重复混入这些本地工具总量。
- 未配置价格、全部未定价和部分未定价保持明确标记。
